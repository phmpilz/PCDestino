# Como contribuir

Todas as mudanças no PCD Destino devem ser feitas por pull request. A branch `main` é protegida e não aceita commits diretos.

1. Crie uma branch a partir da `main`.
2. Faça uma alteração pequena e bem delimitada.
3. Execute `npm run typecheck`.
4. Abra um pull request usando o modelo do repositório.
5. Aguarde a verificação automática e a revisão obrigatória.

Relatos públicos não devem conter dados pessoais, informações médicas, endereços particulares ou outros dados sensíveis.
